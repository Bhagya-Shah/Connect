# Connect

Starting with nutrition. One app where people find experts (nutritionists, CAs, lawyers, career coaches and more), and experts run their whole practice: booking, payments, notes, plans and client progress.

## What's here

- `demo/index.html`: a clickable nutrition-first demo with example data. Built around daily meal photos. Two views: Nutritionist (meal photo review feed, clients, diet plans, food logs, calendar, earnings) and User (goal boxes, booking, intake, payment, daily plan, progress, chat).

## Plan for the first real version

- Consultant profile and shareable booking link
- Calendar, slots and booking
- UPI and card payments (Razorpay) with GST invoices
- Video call link
- Client notes, tasks, files and progress tracking
- WhatsApp and email reminders

Planned stack: Next.js (mobile-friendly web app), Supabase, Vercel, Razorpay.
